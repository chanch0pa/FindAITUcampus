# FindIt Campus
Lost & found web app (Astana IT University project). No installs needed, only Node.js 16+.

1. Open this folder in VS Code
2. Open the terminal (Ctrl+) and run: `npm start`  (or `node server.js`, or press F5)
3. Open http://localhost:3000

Register an account to report items and contact posters. Data is stored in `data/` (delete that folder to reset).
Out of scope (as in the plan): university integration, automated matching, native mobile app.
